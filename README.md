# Field Medic Manual

An **unofficial** desktop manual app for the ACE Medical mod in Arma Reforger (Windows, Tauri).
Arma Reforger の ACE Medical MOD 向けの**非公式**デスクトップ マニュアルアプリです（Windows、Tauri 製）。
