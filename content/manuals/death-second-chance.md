# 致命傷と Second Chance

致命打を受けたときに即死するか意識不明で済むか（Second Chance）の判定の流れと部位ごとの確率、倒れた後の追い打ち、Circulation・Hitzones での違い、死亡の条件と死亡を防ぐ設定をまとめる。

> [!NOTE]
> ACE Medical **Dev 1.5.36** のソースコード（[acemod/ACE-Anvil](https://github.com/acemod/ACE-Anvil) の dev ブランチ `703d1aa7`）とゲーム本体 1.8.0.13 の処理を読んで書いた（2026-09-27 確認）。Release 版（1.4.3）では違う場合がある。
> 時間の数値は、コードの式から計算した目安（シングルプレイ）。人の多いサーバーでは、負荷によって全体が 1〜2 割遅く進むことがある（出来事の順番は変わらない）。
> 公式ドキュメント: [ACE Anvil – Medical（Dev）](https://anvil.acemod.org/dev/components/medical/)

関連: [意識喪失と回復](consciousness.md) ／ [出血と止血](hemorrhage.md) ／ [心停止と CPR](cardiac-arrest.md) ／ [サーバー設定の注意点](server-settings.md)

## Second Chance とは

Second Chance は、致命打で即死する代わりに意識不明にする仕組み。既定では、頭への致命打は即死し、胸・腹・手足などへの致命打は必ず助かる。助かった後は、Circulation 入りでは心停止になり、Circulation なしでは自然には目覚めない意識不明になる。

**致命打**とは次の損傷を言う。

| 組み合わせ | 致命打 |
|---|---|
| Hitzones なし（普段の組み合わせ・Core だけ） | 見えない「全体 HP」（最大 100）が 0 になる損傷 |
| Hitzones あり | 急所（頭・胸・腹）か心臓が破壊される損傷 |

- 全体 HP は、部位が受けた損傷を本体の倍率で受け取る（頭 3.4、首 3、胸 0.9、腹・手 0.7、腰・太もも 0.65、上腕・前腕・すね 0.5、足 0.425。破片は × 0.25）。例: 頭に 30 の損傷 → 頭（30 HP）が破壊され、全体 HP は 102 減って 0 になる。胸に 70 の損傷なら全体 HP は 63 減る。
- ACE は全体 HP を「0 で死亡」の部位から外している。全体 HP が 0 になっても直ちには死なず、Second Chance の判定で死ぬかどうかが決まる。
- 全体 HP が 0 になると、最後に撃たれた部位に必ず出血が付く。

**助かった後**の違い:

| 組み合わせ | 助かった後 |
|---|---|
| Circulation あり（普段の組み合わせ） | 心停止になる（最初の 1 回だけ）。CPR で蘇生させる（[Circulation を入れているときの結果](#circulation-を入れているときの結果)） |
| Circulation なし | 意識の値が 0 になり、回復倍率が 0 になる。既定ではエピネフリンを打たないと目覚めない（[エピネフリンで起こす](consciousness.md#エピネフリンで起こす)） |

**Second Chance が無いもの**（既定）:

| 設定 | 意味 | 既定値 |
|---|---|---|
| `m_bSecondChanceForAIEnabled` | AI にも Second Chance を与えるか | false（AI は致命打で即死） |
| `m_bSecondChanceForFallDamageEnabled` | 落下の損傷で意識を失ったときにも与えるか | false（落下による致命傷は即死） |

2026-09-27 の実機での印象（頭部の損傷以外で即死した印象はない）は、既定の確率（頭 0、ほか 1）と合う。

## 判定の流れと部位ごとの確率

判定は 2 回ある。1 回目は致命打の瞬間に「致命打を受けた部位」を、2 回目は意識を失ってから 1 秒後に「その時点で壊れている部位すべて」を判定する。1 つでも外れたら死亡する。助かる確率は、関わる部位の確率の積になる。

1. 致命打を受ける（全体 HP が 0、または Hitzones で急所・心臓の破壊）。
2. 次のどれかに当たれば、その場で死亡する: 致命打の部位が無い／Second Chance が無効（AI・落下）／意識を失ってから 1 秒以上たっている／致命打の部位の確率で外れた。
3. 当たらなければ助かり、意識不明になる（Circulation 入りでは心停止）。
4. 意識を失ってから 1 秒後に、その時点で壊れている部位をすべて判定する。1 つでも外れたら死亡する。
5. 助かった部位は、それぞれ最大 HP の 1% だけ回復する（壊れた状態から抜ける）。

`助かる確率 = 致命打の部位の確率 × 1 秒後に壊れている他の部位の確率の積`

| 部位 | 確率の設定 | 既定値 |
|---|---|---|
| 頭 | `m_fSecondChanceOnHead` | 0 |
| 胸 | `m_fSecondChanceOnChest` | 1 |
| 腹 | `m_fSecondChanceOnAbdomen` | 1 |
| 首・腰・腕・脚 | `m_fDefaultSecondChance` | 1 |
| 心臓（Hitzones） | `m_fSecondChanceOnHeart` | 0（2 回判定する。[Hitzones の急所と心臓](#hitzones-の急所と心臓)） |
| 大腿動脈（Hitzones） | 設定なし | 1 |

- 確率が 1 以上なら必ず助かる。1 未満なら判定のたびに乱数を振る。
- 一度助かった部位は、目覚めるまで判定なしで助かる扱いになる（1 回目と 2 回目で同じ部位を二重に振らない）。心臓だけは毎回振り直す。
- 目覚めると記録が消え、次の致命打からまた最初から判定する。
- 全部の確率を 0 にすると、頭以外への致命打でも即死する（機能を無効にするのに近い）。

計算例:

| 場面 | 助かる確率 |
|---|---|
| Core: 胸に致命打（既定 1） | 100% |
| Core: 頭に致命打（既定 0） | 0% |
| Core: 胸 0.5 に設定して胸に致命打 | 50% |
| Core: 胸 0.5・腹 0.5 に設定して、胸に致命打・腹も破壊 | 25% |
| Core: 胸に致命打・頭も破壊されている | 0% |
| Hitzones: 心臓の破壊（既定 0） | 0% |
| Hitzones: 心臓 0.5 に設定して心臓の破壊 | 25% |
| Hitzones: 胸の破壊と大腿動脈の破壊（どちらも 1） | 100% |
| AI（既定） | 0% |

### 落下による致命傷

- `m_bSecondChanceForFallDamageEnabled` が false のとき、落下の損傷を受けた時刻が意識を失った時刻以後なら、1 秒後の判定で死亡する。1 回目の判定（まだ意識を失っていない）では通るので、死亡は 1 秒後になる。

> [!NOTE]
> 公式ドキュメントとの違い: ドキュメントは「意識を失う前に殺されるときに評価する」とだけ書いている。実際は 2 段階で判定し（致命打の部位 → 1 秒後に壊れている部位すべて）、助かった部位は HP が 1% 戻る。

## 倒れた後の追い打ち

意識を失ってから 1 秒以上たった後に致命打を受けると、確率に関係なく即死する。これは目覚めるまで続く。Second Chance で助かった後の追い打ちも同じ。

| 意識を失ってから致命打まで | 結果 |
|---|---|
| 0 ms | 判定する（確率で助かれば生存） |
| 500 ms | 判定する |
| 999 ms | 判定する |
| 1000 ms | 即死 |
| 5000 ms | 即死 |
| 60000 ms | 即死 |

- これを避ける設定はない（`m_bPlayerCannotDie` で死亡そのものを無効にする以外。[死亡の条件と死亡を防ぐ設定](#死亡の条件と死亡を防ぐ設定)）。
- Hitzones なし: 全体 HP が 0 のままだと状態が変わらないので、判定自体が起きない。1 秒後の判定で助かった部位が 1% 回復すると、その分だけ全体 HP も戻り（例: 胸なら +0.9）、0 から抜ける。その後に全体 HP が再び 0 になる損傷を受けると即死する。
- Hitzones あり: 意識不明の人の頭・胸・腹・心臓が破壊されると即死する。首・腰・腕・脚の破壊では即死しない（出血は付く）。
- 意識を失ってからの 1 秒以内に 2 回目の致命打を受け、確率で助かった場合、Circulation 入りでも心停止は 2 回目には起こさない（最初の 1 回だけ）。

> [!NOTE]
> 公式ドキュメントとの違い: ドキュメントには、意識不明の人への 1 秒以上後の致命打が即死になることが書かれていない。

## Circulation を入れているときの結果

Circulation を入れていると、Second Chance で助かった人は心停止になる（最初の 1 回だけ）。心停止のまま約 310 s（約 5 分）たつと脳の損傷で死亡する。心停止から戻る手段は CPR による蘇生だけ（[心停止と CPR](cardiac-arrest.md)）。

| 項目 | Circulation あり | Circulation なし |
|---|---|---|
| 助かった直後 | 心停止（状態の次の更新、最大約 1 s 後） | 意識不明（意識の値 0） |
| 目覚め方 | CPR で蘇生 → Stable → 自然に目覚める、または炭酸アンモニウム | エピネフリン（回復倍率が既定 0 のため） |
| `m_fSecondChanceResilienceRegenScale` | 効かない | 効く（既定 0） |
| 放置した場合 | 脳が約 310 s で破壊され死亡 | 意識不明のまま（出血していれば出血死） |

- 心停止中の脳は、心停止に入って 10 s 後から 0.333 HP/s で減り、`10 + 100 ÷ 0.333 = 310.3 s` で 0 になる。CPR 中は減らない（[脳の損傷と残り時間](cardiac-arrest.md#脳の損傷と残り時間)）。
- CPR のやり方と蘇生の判定は [CPR を行う](cardiac-arrest.md#cpr-を行う)・[蘇生の判定](cardiac-arrest.md#蘇生の判定)、蘇生した後の意識の戻り方は [蘇生した後](cardiac-arrest.md#蘇生した後) と [意識が戻る条件と時間](consciousness.md#意識が戻る条件と時間)。
- Breathing を入れていると、心停止中は SpO2 が下がり、約 190 s で 65% を割る。SpO2 が 65% 未満の間は CPR で蘇生しない（[Breathing を入れているとき](cardiac-arrest.md#breathing-を入れているとき)）。
- Hitzones と Circulation の両方を入れていると、心臓の破壊で助かった場合も心停止になる（`m_fSecondChanceOnHeart` の既定 0 では即死）。

### 心停止に入るほかの経路

Second Chance のほかにも、次のときに心停止になる。詳しくは [心停止に入る経路](cardiac-arrest.md#心停止に入る経路)。

| 経路 | 条件（既定値） |
|---|---|
| 心拍数 | 20 未満、または 220 超（出血性ショックの頻脈で血液 25% 前後） |
| 平均動脈圧 | 5.21 kPa（39.1 mmHg）未満 かつ 心拍数 30 以下、または 29.5 kPa 超 |
| 血液量 | 20% 以下（Class IV） |
| CPR をやめる | 蘇生中に CPR をやめると心停止に戻る |
| SpO2（Breathing） | 65% 未満 |
| 気胸（Breathing） | 気胸が最大（0.75）まで悪化したとき |

### AI の場合

- AI は既定で Second Chance が無い（`m_bSecondChanceForAIEnabled` = false）ので、致命打で即死する。
- AI は既定で、心停止に入った瞬間に死亡する（`m_bCardiacArrestForAIEnabled` = false）。出血した AI は血液 25% 前後で、気道が塞がった AI は約 15 分で死にうる（[AI の心停止](cardiac-arrest.md#ai-の心停止)）。

## Hitzones の急所と心臓

Hitzones を入れると全体 HP が無くなり、頭・胸・腹（急所）か心臓が破壊されたときに Second Chance を判定する。心臓は既定の確率 0 なので、破壊されると即死する。首・腰・腕・脚は破壊されても即死しない。

- 全体 HP は部位から損傷を受けなくなり、常に満タンになる。
- 部位が破壊されると、急所かどうかに関係なく必ず出血が付く。
- 診察画面の全体の健康度は、全部位の HP の割合の最小値になる。
- Circulation なしのエピネフリンの健康度の条件は効かなくなる（[エピネフリンで起こす](consciousness.md#エピネフリンで起こす)）。
- この組み合わせは実機では確かめていない（普段の組み合わせは Hitzones なし）。

| 部位 | 急所 | 中の臓器 | 確率（既定） | 破壊されたとき |
|---|---|---|---|---|
| 頭 | ○ | — | 0 | 出血 + 判定 → 既定で死亡 |
| 胸 | ○ | 心臓 | 1 | 出血 + 判定 → 助かる |
| 腹 | ○ | — | 1 | 出血 + 判定 → 助かる |
| 腰 | — | （大腿動脈の出血を合算） | 1 | 出血 |
| 首 | — | — | 1 | 出血（負傷の段階ですでに出血と意識喪失） |
| 腕・脚 | — | 太ももに大腿動脈 | 1 | 出血 |
| 心臓 | ○ | — | 0（2 回判定） | 判定 → 既定で死亡 |
| 大腿動脈 | — | — | 1 | 60% 以下で腰に大出血 + 意識喪失 |

### 心臓

- 胸の中にある臓器で、最大 30 HP、半径 4 cm の球。銃弾の損傷を 15 倍、近接を 3 倍で受ける。爆発・火などでは損傷を受けない。
- 胸を撃った弾（銃弾・近接）の軌道の延長が、心臓の中心から 4 cm 以内を通ると心臓も損傷を受ける。
- 破壊に要る損傷は、銃弾で `30 ÷ 15 = 2`、近接で `30 ÷ 3 = 10`（胸の部位の倍率を掛ける前か後かで、壊れやすさは変わる）。
- 心臓の判定は、致命打の瞬間と 1 秒後の 2 回とも乱数を振るので、助かる確率は `m_fSecondChanceOnHeart` の 2 乗になる。

`心臓の破壊で助かる確率 = p × p`（p = `m_fSecondChanceOnHeart`）

| p | 助かる確率 |
|---|---|
| 0（既定） | 0% |
| 0.5 | 25% |
| 1 | 100% |

### 大腿動脈と首

- 大腿動脈と首の大出血は [首と大腿動脈の大出血](hemorrhage.md#首と大腿動脈の大出血)。

### 設定

| 設定 | 意味 | 既定値 |
|---|---|---|
| `m_bOrganHitZonesEnabled` | 臓器（心臓・大腿動脈）を使うか。false なら心臓の即死と大腿動脈の大出血が無くなる | true |
| `m_fSecondChanceOnHeart` | 心臓の確率 | 0 |
| `m_bInstantUnconOnMassiveBleeding` | 首・大腿動脈の大出血でその場で意識を失うか | true |

> [!NOTE]
> 公式ドキュメントとの違い: ドキュメントは心臓を「Second Chance を評価する」、確率を設定値としている。実際は 2 回判定するので、助かる確率は設定値の 2 乗になる。

## 死亡の条件と死亡を防ぐ設定

ACE が死亡させるのは、Second Chance で外れたとき、意識を失って 1 秒以上後の致命打、出血死、Circulation の脳の破壊（心停止の放置）などで、どれも同じ死亡処理を通る。`m_bPlayerCannotDie` を true にすると、この処理による死亡がプレイヤーだけ無効になる（AI は死ぬ）。

| 死亡の経路 | 組み合わせ | 条件 |
|---|---|---|
| 致命打で Second Chance が外れる | すべて | [判定の流れと部位ごとの確率](#判定の流れと部位ごとの確率) |
| 1 秒後の判定で外れる | すべて | 壊れている部位のどれかが外れる |
| 意識を失って 1 秒以上後の致命打 | すべて | [倒れた後の追い打ち](#倒れた後の追い打ち) |
| 出血死 | すべて | 血液が 0（プレイヤーは `m_bBleedOutForPlayersEnabled` が true のとき） |
| 溺水 | すべて | 意識不明で溺れると頭に大きな損傷を受け、頭の確率 0 で死亡する |
| 脳の破壊 | Circulation あり | 心停止のまま約 310 s |
| 心停止した AI | Circulation あり | `m_bCardiacArrestForAIEnabled` が false（既定）なら心停止の瞬間 |

| 設定 | 意味 | 既定値 |
|---|---|---|
| `m_bPlayerCannotDie` | true にすると、プレイヤーは上の経路で死なない | false |
| `m_bBleedOutForPlayersEnabled` | プレイヤーが出血死するか（AI は常に出血死する） | true |
| `m_bCardiacArrestForAIEnabled` | AI が心停止に入れるか（false なら心停止で即死） | false |

### 死亡を無効にしたとき

- 出血死しない設定では、血液が 0 になっても意識不明のまま残る。血液を 33.3% より上に戻せば目覚めうる（Circulation なし）。
- `m_bPlayerCannotDie` が true でも、次の死亡は防げない（本体の「無敵を無視して殺す」処理を使うため）: リスポーン画面からの自殺、Capture & Hold のスポーン地帯、Clean Sweep、ハブの範囲など。そのため、プレイヤーはリスポーン画面の自殺でやり直せる。
- ゲームマスターの「破壊」（Neutralize）と溺水は同じ死亡処理を通るので、`m_bPlayerCannotDie` が true なら防がれる。
- 設定の書き方の注意は [書き漏らすと危険な設定](server-settings.md#書き漏らすと危険な設定)、既定値の一覧は [主な設定の既定値](server-settings.md#主な設定の既定値)。
