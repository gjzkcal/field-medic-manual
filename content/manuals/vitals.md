# バイタルと状態の見方

脈・血圧・呼吸数・SpO2 の確かめ方と正常値、Circulation の 5 つの状態（Stable / Unstable / Critical / 心停止 / 蘇生中）の閾値、心拍数と血圧がどう決まるか、診察画面と画面の効果をまとめる。バイタルは Circulation を入れたときだけある（呼吸数と SpO2 は Breathing も必要）。

> [!NOTE]
> ACE Medical **Dev 1.5.36** のソースコード（[acemod/ACE-Anvil](https://github.com/acemod/ACE-Anvil) の dev ブランチ `703d1aa7`）とゲーム本体 1.8.0.13 の処理を読んで書いた（2026-09-27 確認）。Release 版（1.4.3）では違う場合がある。
> 時間の数値は、コードの式から計算した目安（シングルプレイ）。人の多いサーバーでは、負荷によって全体が 1〜2 割遅く進むことがある（出来事の順番は変わらない）。
> 公式ドキュメント: [ACE Anvil – Medical（Dev）](https://anvil.acemod.org/dev/components/medical/)

関連: [心停止と CPR](cardiac-arrest.md) ／ [痛みと薬](pain-medications.md) ／ [出血と止血](hemorrhage.md) ／ [呼吸と気胸](breathing.md) ／ [気道管理](airway.md) ／ [意識喪失と回復](consciousness.md)

## バイタルを確かめる操作

確かめる方法は 2 つある。結果はどちらも画面の通知（英語）で出る。

| 方法 | 相手 | 所要時間 | 開き方 |
|---|---|---|---|
| 医療ラジアルメニューの「診察する（Examine patient）」 | 照準の先のキャラクターなら誰でも（意識があっても） | なし（すぐ出る） | 既定 Ctrl+H |
| 体への操作 | 意識不明の相手だけ | 押し続け 3 s | 相手の体の部位を見て操作 |

| 項目 | 体の操作の名前と部位 | 通知の文 | 必要な MOD |
|---|---|---|---|
| 脈 | 「Check pulse」（頭・胸・腕・脚） | You find a heart rate of 80 | Circulation |
| 血圧 | 「Check blood pressure」（腕・脚） | You find a blood pressure of 119/79 mmHg（収縮期/拡張期） | Circulation |
| 呼吸数 | 「Check respiratory rate」または「Check Breathing」（頭。場面で表記が変わり、実機で両方を確認） | You find a respiratory rate of 14 breaths per minute | Breathing |
| SpO2 | 「Check SpO2」（腕） | You find a SpO2 of 97% | Breathing |

- 通知の数値は**小数点以下を切り捨て**て出る（心拍数 79.9 なら 79）。
- 体への操作は、ラグドール中・水中・落下中のときと、手に道具を持っているときは出ない。
- 確かめる操作は、患者の状態を変えない。
- 表示は英語のまま（Circulation・Breathing には日本語訳がない）。
- ゲームマスターは、キャラクターのツールチップの「Vital signs」（心拍数と血圧。四捨五入、1 s ごとに更新）と「Brain」（脳の残り）で見られる。

### Circulation なし（Core だけ）の場合

- バイタル（脈・血圧）はなく、確かめる操作もない。診察画面の本体の表示（出血・止血帯など）で見る（[出血の見分け方](hemorrhage.md#出血の見分け方)）。

## 正常値と表示

無傷のキャラクターの値:

| 項目 | 内部の値 | 通知に出る値 | 決める設定（既定値） |
|---|---|---|---|
| 心拍数 | 80 bpm | 80 | `m_fDefaultHeartRateBPM`（80） |
| 血圧 | 収縮期 120.0 / 拡張期 80.0 mmHg（平均 93.3 mmHg = 12.443 kPa） | **119/79**（実機で確認） | `m_fDefaultMeanArterialPressureKPA`（12.443）、`m_fDefaultPulsePressureKPA`（5.3329） |
| 呼吸数（Breathing） | 14.573 回/分 | 14 | `m_fDefaultRespiratoryRateBPM`（14.573） |
| SpO2（Breathing） | 97.149% | 97 | —（既定値の釣り合いで決まる） |
| 一回拍出量 | 95 ml | 出ない | `m_fDefaultStrokeVolumeML`（95） |
| 心拍出量 | 7600 ml/分 | 出ない | — |

| Unstable になる平均血圧の境目 | 7.11 kPa（53.3 mmHg） | 68/45 | — |

| CPR 中（血液 100%、心拍数 105.3） | 3.77 kPa（28.3 mmHg） | 36/24 | 100〜120 の乱数 |
| 心停止中 | 0 | 0/0 | 0 |

## 5 つの状態と閾値

Circulation を入れると、生存しているキャラクターは次の 5 つの状態のどれかになる。サーバーが約 1 s ごとに判定する。

| 状態 | 起きること |
|---|---|
| Stable（安定） | 意識不明なら自然に目覚める（抵抗値が 1.2 HP/s × 脳の割合で回復。CPR で蘇生した後は 0.8 HP/s × 脳の割合）。炭酸アンモニウムが効く |
| Unstable（不安定） | これだけでは意識を失わない。ただし意識不明なら自然には目覚めない（回復が 0）。炭酸アンモニウムは効かない |
| Critical（重篤） | **入った瞬間に意識を失う**。血液 40% 未満なら頻脈が始まる |
| 心停止（Cardiac arrest） | 心拍数・血圧が 0。意識不明。10 s 後から脳が減り、約 5 分で死亡（[心停止と CPR](cardiac-arrest.md)） |
| 蘇生中（Resuscitation） | CPR を受けている間。脳は減らない |

### 閾値

次のどれか 1 つでも当たると、その状態に移る。判定は「心停止 → Critical → Unstable」の順で、最初に当たったものになる（Stable から直接 Critical や心停止に移ることもある）。

| 条件 | → Unstable | → Critical | → 心停止 |
|---|---|---|---|
| 心拍数が下限より低い | < 40 | < 30 | < 20 |
| 心拍数が上限より高い | > 220 | > 220 | > 220 |
| 平均血圧が下限より低く、かつ心拍数がこの値以下 | < 7.11 kPa（53.3 mmHg）かつ ≤ 80 | < 5.21 kPa（39.1 mmHg）かつ ≤ 40 | < 5.21 kPa かつ ≤ 30 |
| 平均血圧が上限より高い | > 29.5 kPa（221.3 mmHg） | > 29.5 kPa | > 29.5 kPa |
| 血液の残り | ≤ 70%（Class II） | ≤ 40%（Class III） | ≤ 20%（Class IV） |
| SpO2（Breathing のみ） | < 85% | < 75% | < 65% |

- 式: `当たる ⇔ (心拍数 < 下限) または (心拍数 > 上限) または (平均血圧 < 下限 かつ 心拍数 ≤ 条件の値) または (平均血圧 > 上限) または (血液の割合 ≤ 分類の閾値) または (SpO2 < 閾値)`
- 戻るとき（Unstable → Stable、Critical → Unstable）は、その状態の条件に**どれも当たらなくなった**時点で戻る。戻りの余裕（ヒステリシス）はない。
- 心拍数と平均血圧の上限は 3 つとも同じなので、**高すぎる心拍数・血圧では Stable からいきなり心停止**する（エピネフリン・フェニレフリンの過量投与。[過量投与](pain-medications.md#過量投与)）。

計算例:

- 薬も痛みもなく心拍数 80 のままなら、平均血圧は `12.443 × 血液の割合` kPa。平均血圧で Unstable になるのは血液 57.1% 未満だが、その前に血液 70% で Unstable になる。出血では血液の分類が先に効く。
- 血液 100% で心拍数が 33 まで下がると、平均血圧 `12.443 × 33 ÷ 80 = 5.13 kPa` < 5.21 かつ 心拍数 ≤ 40 → Critical。心拍数 30 なら心停止。

### 設定

閾値はサーバーの設定 `m_UnstableThresholds` / `m_CriticalThresholds` / `m_CardiacArrestThresholds` の中にある。項目は `m_fHeartRateLowBPM`（心拍数の下限）、`m_fHeartRateHighBPM`（上限）、`m_fMeanArterialPressureLowKPA`（平均血圧の下限）、`m_fMaxHeartForMeanArterialPressureLowBPM`（平均血圧の下限を使う心拍数の上限）、`m_fMeanArterialPressureHighKPA`（平均血圧の上限）、`m_eBloodState`（血液の分類）、`m_fSpO2`（Breathing）。既定値は上の表のとおり。

> [!WARNING]
> 閾値の項目にはスクリプトの既定値がない。ミッションヘッダーで Circulation の設定を書くときに 1 つでも書き漏らすと 0 になり、例えば `m_fHeartRateHighBPM` が 0 だと全員がすぐ心停止する。Breathing 入りで `m_fSpO2` を書き漏らすと、SpO2 で状態が悪化しなくなる（[書き漏らすと危険な設定](server-settings.md#書き漏らすと危険な設定)）。

### 血液の分類

| 分類 | 血液の残り（3000 ml が満タン） | 診察画面・インベントリの表示 |
|---|---|---|
| Normal | 100% | なし |
| Class I | 70〜100% | Class I hemorrhage |
| Class II | 40〜70%（70% ちょうどを含む） | Class II hemorrhage |
| Class III | 20〜40%（40% ちょうどを含む） | Class III hemorrhage |
| Class IV | 0〜20%（20% ちょうどを含む） | Class IV hemorrhage |
| Fatal | 0 | 死亡 |

満タンから少しでも減ると Class I になるとみられる（本体の処理からの推定）。

### 出血が続いたときの状態の移り方

出血の速さごとの、状態が変わる時刻と、その時の血液の残り（薬・痛みなし）:

| 出血の速さ | → Unstable | → Critical（意識喪失） | → 心停止 |
|---|---|---|---|
| 15 ml/s | 61 s（69.5%） | 121 s（39.5%） | 150 s（25.0%、心拍数 222） |
| 40 ml/s | 23 s（69.3%） | 46 s（38.7%） | 58 s（22.7%、心拍数 225.9） |
| 100 ml/s | 10 s（67.4%） | 23 s（38.4%） | 31 s（19.3%、Class IV） |

> [!NOTE]
> 公式ドキュメントとの違い:
> - ドキュメントのバイタルの表は、Unstable・Critical の血圧の条件を血圧だけで書いているが、実際は「心拍数 ≤ 80」「心拍数 ≤ 40」も満たすときだけ当たる。心停止の注記「HR < 30」は、ソースでは「≤ 30」。
> - Critical の血圧はドキュメントでは 51/34 未満だが、式から計算すると 50.24/33.49（通知では 50/33）。
> - 出血による心停止は Class IV ではなく、多くは Class III の中（血液 25% 前後）で頻脈によって起きる（[心拍数の決まり方](#心拍数の決まり方)）。
> - Breathing の説明には「気道が塞がると Unstable」とあるが、直接その規則はない。無呼吸で SpO2 が 85% を割ると（約 16 s 後）Unstable になる。

### Breathing を入れている場合

- SpO2 の条件（85 / 75 / 65%）が加わる。戻るときは SpO2 が閾値以上であることも必要。
- 気道が塞がっている間は、状態に関係なく意識が戻らない（[気道と意識](consciousness.md#気道と意識)）。
- 気胸が最大（0.75）まで進むと、状態が心停止に切り替わる（設定 `m_fPneumothoraxArrestEnabled`、既定 true）。

### Circulation なし（Core だけ）の場合

- 5 つの状態はなく、生存・意識不明・死亡だけ。血液の分類（Class）もない。意識は抵抗値と血液量で決まる（[意識を失う条件](consciousness.md#意識を失う条件)、[血液量と出血の段階](bleeding-system.md#血液量と出血の段階)）。

## 心拍数の決まり方

- 心拍数は「目標の心拍数」に向かって、毎秒、残りの差の半分ずつ近づく。
- 目標は 80。痛みがあると最大 130 に上がり、薬で上下する。Breathing では頻呼吸（気胸）でも上がる。
- 出血で血液が 40% を切り Critical になると、頻脈が始まる。血液が約 26% を切ると目標が 220 を超え、**心停止する**。
- Stable・Unstable では、血圧が下がっても心拍数は上がらない（出血しても血液 40% までは 80 のまま）。SpO2 も心拍数に影響しない。

### 式

- `目標 = max(0, max(基本値, 80 + 50 × 痛みの強さ) + 薬の補正)`
- `新しい心拍数 = 前の心拍数 + (目標 − 前の心拍数) × min(0.5 × Δt, 1)`（Δt は前回からの秒数。約 1 s なので、毎秒差の半分）
- 基本値は通常 80（`m_fDefaultHeartRateBPM`）。
- Critical で血液が 40% 未満のとき: `基本値 = 前の心拍数 × 14.3 × (0.5 + 0.5 × b) ÷ max(6, 前の平均血圧 kPa)`。平均血圧が 6 kPa 以上なら `91.94 × (0.5 + 0.5 × b) ÷ b` に落ち着く（b = 血液の割合）。
- 目標が 220 を超えるのは `b < 0.2641`（血液 26.4% 未満）。

| 記号 | 意味 | 既定値 |
|---|---|---|
| 痛みの強さ | 0〜1（[痛みの画面効果](pain-medications.md#痛みの画面効果) と同じ値） | 0 |
| 薬の補正 | エピネフリン +、メトプロロール −、モルヒネ −（[薬の効き方の計算](pain-medications.md#薬の効き方の計算)） | 0 |
| b | 血液の残りの割合 | 1 |

計算例:

- 激痛（痛みの強さ 1）、薬なし → 目標 130。80 から 1 s 後 105、2 s 後 117.5、3 s 後 123.8。実機でも、手足を撃たれて意識を失った AI の心拍数は 130 だった。
- Critical の頻脈の目標: 血液 35% → 177.3、30% → 199.2、25% → 229.8（> 220 で心停止）。
- 実際に心停止する血液量は出血の速さで少し変わる（15 ml/s で 25.0%、40 ml/s で 22.7%、100 ml/s は心拍数の上昇が間に合わず 19.3% = Class IV の閾値が先）。

1 本のピークでの薬の補正: エピネフリン +25.2 bpm、メトプロロール −16.5 bpm、モルヒネ −13.1 bpm。

### 特別な状態の心拍数

| 状態 | 心拍数 |
|---|---|
| 心停止 | 0 |
| 蘇生中（CPR） | 100 + 正規乱数の絶対値（標準偏差 6.667、0〜20 に切り詰め）。平均 105.3、100〜120 の間 |
| 蘇生した直後 | 30（Critical の下限）から始まり、次の更新で 55、その後 80 へ |

### Breathing を入れている場合

- `基本値 = 80 + 2 × max(0, 呼吸数 − 14.573)`（頻呼吸の分だけ上がる）
- 気胸 0.54 → 呼吸数 31.68 → 目標 114.2。0.72 以上 → 呼吸数 40 → 目標 130.9。
- 緊張性気胸・気道閉塞では呼吸数が 0 なので、心拍数は上がらない。

## 血圧の決まり方

- 平均血圧（平均動脈圧、MAP）は「心拍数 × 一回拍出量 × 血管抵抗」。一回拍出量は血液量に比例するので、薬と痛みがなければ**平均血圧は血液の割合に比例**する（血液 50% で 47 mmHg）。
- 通知の上下の値は、平均血圧から決まった比で作る（収縮期 = 1.286 × 平均、拡張期 = 0.857 × 平均）。上下の値に、平均血圧以外の情報はない。
- 状態の判定に使うのは平均血圧（と心拍数・血液量）で、上下の値は使わない。

### 式

- `一回拍出量 = 95 × 血液の割合`（CPR 中はさらに × 0.23）ml
- `心拍出量 = 心拍数 × 一回拍出量` ml/分
- `平均血圧 = 心拍出量 × 血管抵抗` kPa（血管抵抗 = 既定 0.0016372 + 薬の補正）
- `脈圧 = 0.4286 × 平均血圧`
- `拡張期 = 平均血圧 − 脈圧 ÷ 3`、`収縮期 = 平均血圧 + 2 × 脈圧 ÷ 3`
- `通知の値 = 切り捨て(7.5006 × kPa)`

| 記号 | 意味 | 既定値 |
|---|---|---|
| 95 | `m_fDefaultStrokeVolumeML`（一回拍出量） | 95 ml |
| 0.23 | `m_fCPRStrokeVolumeScale`（CPR 中の一回拍出量の倍率） | 0.23 |
| 既定の血管抵抗 | `m_fDefaultMeanArterialPressureKPA ÷ (m_fDefaultHeartRateBPM × m_fDefaultStrokeVolumeML)` = 12.443 ÷ (80 × 95) | 0.0016372 |
| 0.4286 | `m_fDefaultPulsePressureKPA ÷ m_fDefaultMeanArterialPressureKPA` = 5.3329 ÷ 12.443 | 0.4286 |

計算例: 血液 60%、心拍数 80、薬なし → 一回拍出量 57 ml → 心拍出量 4560 ml/分 → 平均血圧 `4560 × 0.0016372 = 7.466 kPa`（56.0 mmHg）→ 通知 71/47。

| 経過 | 血液 | 分類 | 状態 | 心拍数 | 通知の血圧 |

- Critical に入ると頻脈で心拍出量が増えるので、**血圧がいったん上がって見える**（120 s の 47/31 から 130 s の 90/60 へ）。
- 心拍出量は出血の上限（`max(20, 心拍出量 ÷ 60)` ml/s）にも使われる（[傷の出血率](bleeding-system.md#傷の出血率)）。

### 薬による変化

- フェニレフリンは血管抵抗を上げる（1 本のピークで +47%、平均血圧 137 mmHg）。
- モルヒネは血管抵抗を少し下げる（−4.9%）。
- エピネフリン・メトプロロールは心拍数を通じて血圧を変える。

### Breathing を入れている場合

- 気胸は血圧を下げない。気胸で頻呼吸になると心拍数が上がるので、平均血圧はむしろ上がる（気胸 0.75 で心拍数 130.9、平均血圧 153 mmHg）。

> [!NOTE]
> 公式ドキュメントとの違い:
> ドキュメントでは緊張性気胸で血圧が下がるとあるが、ソースには血圧を下げる処理がない。緊張性気胸は呼吸を止める（無呼吸にする）だけ。

## 呼吸数と SpO2

- Breathing を入れたときだけある。
- 呼吸数は**気胸の大きさだけ**で決まる。気道が塞がる（舌根沈下・嘔吐）、緊張性気胸、心停止で 0 になる。CPR 中は 0.3。
- 無呼吸になると SpO2 は **16 s で 85% 未満（Unstable）、85 s で 75% 未満（Critical・意識喪失）、約 15 分（914 s）で 65% 未満（心停止）**。
- SpO2 の低下・無呼吸には、画面の効果も音もない（[画面の効果](#画面の効果)）。

### 呼吸数の式

- `呼吸数 = min(40, 14.573 ÷ (1 − 気胸の大きさ))`
- 気道閉塞・緊張性気胸・心停止のときは 0、蘇生中（CPR）は 0.3。

| 記号 | 意味 | 既定値 |
|---|---|---|
| 14.573 | `m_fDefaultRespiratoryRateBPM` | 14.573 回/分 |
| 40 | `m_fMaxRespiratoryRateBPM` | 40 回/分 |
| 気胸の大きさ | 肺の容積が失われた割合（0.18 刻み、最大 0.75） | 0 |

開放性気胸の段階ごとの値（各段階で 300 s たった後）:

| 気胸の大きさ | 呼吸数（通知） | 心拍数 | 平均血圧 | SpO2 | 状態 |
|---|---|---|---|---|---|
| 0 | 14.57（14） | 80.0 | 93 mmHg | 97.15% | Stable |
| 0.18 | 17.77（17） | 86.4 | 101 mmHg | 96.14% | Stable |
| 0.36 | 22.77（22） | 96.4 | 112 mmHg | 95.17% | Stable |
| 0.54 | 31.68（31） | 114.2 | 133 mmHg | 94.31% | Stable |
| 0.72 | 40.00（40） | 130.9 | 153 mmHg | 90.76% | Stable |
| 0.75 | 40.00（40） | 130.9 | 153 mmHg | 89.52% | Stable |

気胸があっても状態は Stable のままで、SpO2 は少ししか下がらない（詳しくは [開放性気胸と緊張性気胸](breathing.md#開放性気胸と緊張性気胸)）。

### 無呼吸（気道閉塞）での SpO2 の推移

血液が満タンで、気道が塞がったまま放置した場合:

<!-- chart: x=経過; y=SpO2; ref=85, 75, 65; data=data/apnea-spo2.csv -->

| 経過 | SpO2 | 状態 |
|---|---|---|
| 0 s | 97.1% | Stable |
| 5 s | 92.0% | Stable |
| 10 s | 88.1% | Stable |
| 16 s | 85% 未満 | Unstable |
| 30 s | 79.5% | Unstable |
| 60 s | 75.7% | Unstable |
| 85 s | 75% 未満 | Critical（意識喪失） |
| 3 分 | 73.8% | Critical |
| 5 分 | 72.4% | Critical |
| 7 分 | 71.2% | Critical |
| 10 分 | 69.3% | Critical |
| 12.5 分 | 67.5% | Critical |
| 15 分 | 65.2% | Critical |
| 914 s（約 15 分 14 秒） | 65% 未満 | 心停止 |

- 最初の 1 分は速く下がり、75% 付近からはゆっくりになる（無呼吸の間も、肺に残った酸素が少しずつ血液に移るため）。
- 実機（シングルプレイ、AI）でも 2 分 74%、5 分 72%、10 分 69% で、14 分 43 秒で心停止した（撃たれた AI の失血で少し早まった）。人の多いサーバーでは 17 分 35 秒かかった。
- 閉塞から 900 s 以内に気道を開ければ、25 s 以内に SpO2 が 85% 以上に戻り Stable になる（[放置したときの推移](airway.md#放置したときの推移)）。
- 緊張性気胸の無呼吸は、肺が小さい分だけ速い（気胸 0.18 で 827 s、0.36 で 727 s、0.54 で 604 s、0.72 で 433 s）。

### そのほかの SpO2 の動き

| 場面 | SpO2 |
|---|---|
| 心停止中（原因によらない） | 190 s で 97% → 65% を割る。65% 未満では CPR で蘇生しない（[Breathing を入れているとき](cardiac-arrest.md#breathing-を入れているとき)） |
| 出血（600 s 後の値） | 血液 90% で 95.3%、70% で 91.2%、50% で 86.7%、40% で 84.2%。状態は血液の分類が先に決める |
| 酸素マスク（気道が開いているとき） | 1 分で 99.8%（[酸素マスクを使う](breathing.md#酸素マスクを使う)） |

> [!NOTE]
> 公式ドキュメントとの違い:
> 設定 `m_bPaCO2Enabled` は「PaCO2 と呼吸数への影響を有効にする」とあるが、どこからも読まれていない。無呼吸で PaCO2 は 3 分で 39 → 57 mmHg に上がり、その後も上がり続けるが、呼吸数は変わらない。また、緊張性気胸では呼吸数は 0 になる（ドキュメントの「開放性・緊張性とも呼吸数と心拍数が上がる」とは違う）。

## 診察画面の表示

- 診察画面（負傷者を診察 / Inspect casualty）に、Circulation 入りで**出血の分類（Class I〜IV hemorrhage）**と**投薬記録（最新 8 件）**が加わる。
- **心拍数・血圧の数値は診察画面には出ない**。バイタルは [バイタルを確かめる操作](#バイタルを確かめる操作) で見る。
- Breathing 入りで、気胸（Open pneumothorax / Tension pneumothorax。緊張性を優先して表示）が出る。

### Circulation を入れている場合

- 診察の操作は、本体の条件に加えて「痛みの HP が少しでも減っている」「状態が Stable でない」ときにも出る。
- 診察画面は 10 s 表示される。
- 医療ラジアルメニューの「診察する」から離れた位置でも開けるが、相手との距離が 3 m を超えると薄くなり、4 m 以上で閉じる（この距離の挙動は本体の診察画面のもので、Circulation がなくても同じ）。
- 自分のインベントリでは、血液の表示が Class I〜IV になり、出血の欄が Class I から出る。投薬記録はツールチップに出る。
- 投薬記録の形式は [投薬記録](pain-medications.md#投薬記録)。

### Breathing を入れている場合

| 状態 | 見え方 |
|---|---|
| 開放性気胸 | 診察画面とインベントリに「Open pneumothorax」 |
| 緊張性気胸 | 同「Tension pneumothorax」。呼吸数 0 |
| 嘔吐による気道閉塞 | 頭に「Clear vomit」の操作が出る。呼吸数 0 |
| 舌根沈下 | **直接は見えない**（「Lift chin」は塞がっていなくても出る）。呼吸数 0 で見分ける |
| King LT・酸素マスク | 口元に付けた物が見える |

- インベントリの気胸の表示は、自分のキャラクターの状態を出す。
- 詳しくは [気道閉塞の見分け方](airway.md#気道閉塞の見分け方)。

### Circulation なし（Core だけ）の場合

- 本体の表示（出血・止血帯・生理食塩水など）に、Core が骨折（腕・脚）の表示を足す。全体の損傷度は ACE の全体の健康度で計算し直している（Hitzones では最も減った部位の割合）。

## 画面の効果

自分のキャラクターの状態で、自分の画面に出る効果:

| 状態 | 画面・音 |
|---|---|
| 心停止・蘇生中（Circulation） | 画面がほぼ真っ黒（不透明度 0.85）になり、心停止用の音の合図が入る |
| 意識不明（本体の処理） | 暗いマスクが 0.5 s ごとに揺れる。開き具合は抵抗値（0 → 75 で開いていく）で決まり、血液が最も少ない段階（Circulation では Class IV、20% 以下）では最も閉じる |
| 痛みあり・意識あり（Core） | 白い点滅（[痛みの画面効果](pain-medications.md#痛みの画面効果)） |
| 失血（本体の処理） | 画面の色が抜ける（[出血の見分け方](hemorrhage.md#出血の見分け方)） |
| SpO2 の低下・無呼吸・気道閉塞（Breathing） | **何も出ない** |

> [!WARNING]
> Breathing の無呼吸・SpO2 の低下には、画面の効果も音もない（意識不明の暗いマスクも、SpO2 や気道には反応しない）。画面や音で気づく手がかりはなく、呼吸数・SpO2 を確かめると分かる（[呼吸数と SpO2 を確かめる](breathing.md#呼吸数と-spo2-を確かめる)）。
